# DnsScan
## Ferramenta automatizada para testes de dns

Apenas uma ferramenta que fiz para me ajudar a automatizar alguns testes relacionados ao DNS como:

- Brute force em subdominios
- Brute force cname
- Verificação WHOIS

<hr>

#### Modo de uso
```
python3 dnsscan.py
```


Dependencias PYTHON: dnspython
